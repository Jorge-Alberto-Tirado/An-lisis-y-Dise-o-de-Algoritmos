# Análisis y Diseño de Algoritmos

Este repositorio contiene los trabajos y prácticas realizados durante la materia de **Análisis y Diseño de Algoritmos**.

El objetivo principal fue implementar diferentes algoritmos en lenguaje **C** y analizar su comportamiento mediante distintas versiones de solución, comparando aspectos como su funcionamiento, número de operaciones, tiempo de ejecución y complejidad computacional.

## Contenido

A lo largo del curso se trabajaron temas como:

- Algoritmos de ordenamiento.
- Métodos de búsqueda.
- Fibonacci.
- Subsecuencia común más larga (LCSS).
- Problema de la mochila.
- Dijkstra.
- Árboles de expansión mínima.
- Huffman.
- Estructuras de datos.
- Recursividad y programación dinámica.
- Grafos.
- Autómatas y lenguajes.
- Problemas y proyectos de aplicación.

En varios ejercicios se desarrollaron **diferentes versiones del mismo problema**, por ejemplo soluciones recursivas, iterativas o mediante programación dinámica, con la finalidad de observar cómo cambia su eficiencia.

## Análisis de los algoritmos

Para comparar las implementaciones se utilizaron principalmente:

- Complejidad temporal.
- Conteo de operaciones.
- Tiempo de ejecución.
- Comparación entre diferentes tamaños de entrada.
- Gráficas de crecimiento.

Los resultados obtenidos durante las pruebas fueron almacenados en archivos de datos y utilizados para generar gráficas que permiten visualizar el comportamiento de cada algoritmo.

## Organización del repositorio

Cada carpeta corresponde a un tema o práctica de la materia y contiene los programas desarrollados y sus diferentes versiones.

Dentro de cada carpeta se incluye un archivo `README.md` con una explicación más específica del problema, los algoritmos utilizados y su complejidad.

## Conclusión

Las prácticas realizadas permiten observar que existen diferentes formas de resolver un mismo problema, pero no todas tienen el mismo costo computacional.

El análisis teórico junto con las pruebas experimentales permite comprender cómo la elección de un algoritmo influye directamente en el tiempo de ejecución y en su comportamiento cuando aumenta el tamaño de los datos.
